# 回测框架（v3.1+）

`ccbot_backtest` — 独立可执行文件，不依赖 Qt/网络，Windows/Linux 都能跑。
**回测跑的是实盘引擎本尊**（`CcgEngine`），不是仿制品：通过注入接口实现。

## 设计要点

| 组件 | 说明 |
|---|---|
| **引擎本尊** | 抽出 `ITradingClient` 接口（引擎只用4个方法），实盘用 `TradingClient`，回测用 `SimClient` 模拟撮合——策略逻辑零复制 |
| **虚拟时钟** | `EngineHost` 注入墙钟/单调钟。回放一年只需几秒，用真实时钟的话冷却永远走不完、指标新鲜度检查永远通过，结果会完全失真 |
| **内联执行器** | 回测下单同步完成，确定性可复现 |
| **bar内四子tick** | 每根1m按 O→L→H→C（阳线）/ O→H→L→C（阴线）走价，近似解答"先触下轨还是先反弹" |
| **真实滑点** | 用数据里每分钟的真实买卖价差（`Spread` 列）建模，非固定值。BTC≈4.8bp、小币≈10bp+ |
| **资金费** | 数据自带 `fundingRate` 已对齐结算时刻，持仓过点扣/收 |

## 数据

- 格式：1m CSV，列 `candle_begin_time,open,high,low,close,volume,quote_volume,trade_num,taker_buy_*,Spread,symbol,fundingRate`
- 时间为 **UTC**（用资金费率结算时刻 00/08/16 整点验证）
- 首行若为版权说明会自动跳过；表头按列名定位，不写死顺序
- 跨年目录自动合并（`load_csv_multi`：排序拼接+去重+重算缺口）
- 缺口**不填充**——填充会制造价格静止的假象，网格会在假数据上刷假周期

## 命令

```bash
# 数据集总览（扫描目录下全部CSV）
ccbot_backtest scan <数据目录>

# 单品种质检（K线数/缺口/坏点/资金费点/聚合验证/平均价差）
ccbot_backtest check <CSV文件>

# 二进制缓存（参数网格反复读同一份数据时提速）
ccbot_backtest cache <CSV文件> <输出.bin>

# 单组参数回测
ccbot_backtest run <CSV或.bin> --budget 1000 --lev 3 --layers 6 --curve linear \
    --dynamic --trend --indicator --gates --htf-max 0.6 --headroom 3.0 [--verbose]

# 参数网格寻优（多品种×多组合，并行）
ccbot_backtest sweep <数据根目录> --symbols BTC-USDT,ETH-USDT,SOL-USDT,BNB-USDT \
    --htf 0.60,0.70,0.80 --head 1.5,2.0,3.0

# Walk-Forward 分段验证（判定"最优参数"是真规律还是拟合噪音）
ccbot_backtest wf <数据根目录> --symbols ... --head 1.5,2.0,2.5,3.0,4.0 --segments 4
```

## 输出指标

净盈亏/收益率、**最大回撤**、周期数、胜率、订单数、平均/最大层数、持仓时间占比、
峰值名义、手续费、资金费、三层决策的放行与拦截次数。

**排序一律用 `收益÷回撤`，不用净收益**——按净收益排会选出赌性最大的参数，这是回测最经典的自欺陷阱。

## 防自欺的三道护栏

1. **Walk-Forward**：切成N段独立跑，排序时**跨段一致性优先于总收益**——一个4段全正的参数比"某段暴赚其余段亏"更值得信任
2. **参数高原**：最优值的邻居也必须好。孤峰式的最优 = 拟合噪音
3. **最小样本**：周期数太少的组合不参与排名

## 已完成的实证结论（2026-08）

数据：BTC/ETH/SOL/BNB，2025-01 ~ 2026-08 全量1m，walk-forward 4段。
策略基底：指标首单(1h BOLL+RSI反转25/35) + 动态W + 趋势过滤 + SR雷达，递增6层3倍杠杆。

| 参数 | 旧默认 | 新默认 | 依据 |
|---|---|---|---|
| `sr_headroom_ratio` | 1.5 | **3.0** | 2.5/3.0/4.0 均 **4/4段正收益**（参数高原）；1.5/2.0 在大跌段S3严重亏损(-0.37) |
| `htf_pos_max` | 0.80 | **0.60** | 0.60 **4/4段**；0.80 仅2/4段（拦得太松≈没拦，偶发误拦反而有害） |

**同时必须诚实记录的发现**：三层拦截最优组合(+203U)只比完全不拦截的基线(+181U)好12%。
真正的价值在大跌段——基线 S3 段是 **-0.314**，而 0.60/2.5+ 是 **+0.42**。
即：**三层决策的价值是"在最坏的行情里不亏"，不是"在好行情里多赚"**。

## 边界（必须先说死）

回测能证明"参数在历史上稳不稳"和"A比B好还是差"，**不能证明未来赚钱**。
滑点是模型、极端行情盘口消失无法模拟、样本期市场状态有偏——
它替代拍脑袋，**不替代小资金实盘验证**，两者是接力关系。
