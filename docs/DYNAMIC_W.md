# 动态W模式使用说明（v2.3+）

把整个策略的锚点从"固定百分比"换成"布林带本身"：**补仓锚定下轨、止盈锚定上轨、
间距锚定带宽W**。带子随趋势移动时梯子跟着走，目标是"阶梯式缓跌+带内震荡也能完成
多头周期"。本文按多头（long）讲解，空头方向全部镜像（上下轨互换）。

## 一、开启方式

**GUI 版**：右键品种 → 策略配置 → 勾选"动态W模式"。勾选后指标配置组自动展开
（K线周期/BOLL参数在这里设），实时预览显示当前上下轨。

**headless 版**：config.json 的 bot 里加两个字段：

```json
"dynamic_band_mode": true,
"min_profit_floor": 0.3
```

**开启后哪些配置字段失效**（值仍保存，但引擎不再使用）：

| 失效字段 | 被什么取代 |
|---|---|
| 间隔% (`interval_pct`) | W/3，实时推导（夹逼 0.3~1.5） |
| 止盈% (`tp_pct`) | 触上轨+保底利润双条件 |
| 追踪止盈% (`trail_tp`) | 0.15×W（夹逼 0.2~0.6） |
| 追踪建仓% (`trail_entry`) | 0.1×W（夹逼 0.15~0.4） |

**仍然生效的字段**：预算、杠杆、最大层数、加仓曲线、止损%、冷却、自动重启、
首单模式及全部指标参数（K线周期/BOLL周期倍数/RSI），以及新增的保底利润%。

## 二、三个锚定的精确规则

设当前实时下轨 LB、上轨 UB、带宽 W=(UB−LB)/LB。

**1. 补仓（锚定下轨）** —— 两个条件同时满足才"武装"补仓：

- 距上次建仓价跌幅 ≥ W/3（动态间隔）
- **价格 ≤ 当前下轨**（必须在带外，即统计意义上的超卖位）

武装后开始跟踪最低点，反弹 0.1×W 确认企稳才真正下单（追踪建仓，摊低补仓价）。
注意：带外条件只在武装瞬间检查，武装后即使价格弹回带内，反弹确认单照常执行。

**2. 止盈（锚定上轨）** —— 两个条件同时满足才激活追踪止盈：

- **价格 ≥ 当前上轨**
- 价格 ≥ 均价 × (1 + 保底利润%)，默认 0.3%

激活后跟踪最高点，回撤 0.15×W 全部平仓。保底条款的作用：下跌趋势里上轨可能低于
你的均价（高位库存拖的），只看"触上轨"会亏着卖，保底保证每轮至少覆盖手续费+微利。

**3. 间距（锚定带宽）** —— 上述所有比例每 3 秒按实时 W 重算，波动放大网格自动变疏、
止盈自动放远；缩量震荡自动变密、变近。夹逼上下限防止极端行情把参数推到不合理区间。

**安全冻结**：指标数据超过 180 秒没有更新（断网、K线接口故障）时，自动冻结
"武装新补仓"和"激活止盈"两个动作——宁可错过不可乱做。已激活的追踪止盈继续用
最后一次的参数运行，硬止损（如果设了）不受影响。

## 三、完整周期演算（BTC，1h BOLL(20,2)，3倍杠杆，递增10层）

假设 LB=99000、UB=101000，W≈2.02% → 动态间隔 0.67%、追踪建仓 0.2%、追踪止盈 0.3%。

1. **首单**（指标模式+RSI反转确认）：价格跌破 99000 且 RSI 先探底 25 再回穿 35
   → 首仓成交 @99000
2. **补仓**：价格跌到 98337（−0.67%）且此时下轨已随跌势下移到 98500，
   98337 ≤ 98500 ✓ → 武装；最低探到 98100，反弹 0.2% → 第2仓 @≈98296
3. 重复：每层都要求"跌够动态间隔+仍在带外"，带子下移，补仓位跟着下移，
   均价始终贴在下轨上方 0.5~0.8 个 W 的位置
4. **止盈**：跌势止住、带子走平回升，价格冲到当前上轨 99800，均价 98500，
   保底线 98500×1.003=98796 ≤ 99800 ✓ → 激活追踪；最高冲到 100200，
   回撤 0.3% 平仓 @≈99899
5. **本轮落袋**：(99899−98500)/98500 ≈ 1.42% 价格波动 → 3倍杠杆下保证金 +4.3%
   （扣手续费约 −0.3%，净 +4.0%）
6. 平仓后进入冷却，冷却结束**重新等首单信号**（不会立即市价买回）

## 四、各种行情下的行为

**A. 震荡市（最优场景）**：带子横着走，下轨买上轨卖，多数周期只用 1~2 层，
每轮吃 0.7~1 个 W。

**B. 阶梯缓跌（设计目标）**：跌一段→震一段。每段下跌中梯子跟着下移的下轨补仓，
每次震荡反弹够到上轨就兑现一轮薄利（约 0.2~0.5 个 W），同时清空库存轻装再来。
静态网格在这种行情里均价越套越深，动态模式靠"补仓必须在带外"把均价摁着走。

**C. 瀑布单边跌（结构性弱点）**：价格贴着下轨连续下跌、够不到上轨，只有补仓没有
周期。层数打满后满仓趴窝，等带子回升。**动态模式改变不了纯多策略的这个边界**，
防线是：低杠杆（≤3倍）、够深的梯子、账户总保证金上限、（可选）硬止损。

**D. 上轨低于均价（深套回升期）**：价格触上轨但保底条款不满足 → 不平仓，继续持有。
随着带子上移，某一刻"触上轨"和"≥保底线"同时成立才出场。表现为：深套后不会在
第一次碰上轨时急着亏卖，而是等到至少微利。

**E. 波动率放大**（W 2%→4%）：间隔自动 0.67%→1.33%，追踪止盈 0.3%→0.6%（顶到上限）。
急跌导致的 W 放大会让补仓间距自动拉开，天然减速接飞刀。

**F. 缩量窄幅**（W→0.8%）：W/3=0.27% 被下限夹到 0.3%，追踪参数同理——防止在
极窄震荡里过密交易，手续费吃光利润。

**G. 断网/数据过期**：见"安全冻结"。恢复联网后 3 秒内拿到新数据自动解冻。

**H. 程序重启**：仓位状态从本地恢复，指标数据视为过期（冻结），首次拉取成功后
恢复正常——重启后头几秒不会拿旧轨道值做决策。

## 五、推荐搭配与参数建议

- **首单模式选"指标信号"+ RSI反转确认（cross）**：动态模式管的是"进场后怎么滚"，
  首单质量靠指标闸门。用"立即开仓"也可以，但等于放弃了入场择时
- **加仓曲线**：递增（linear）——均价压得动、深层资金不爆炸。平推偏保守，
  倍投深层过重，不建议三倍/平方
- **保底利润%**：默认 0.3 即可（taker 手续费双边约 0.1%，留 3 倍余量）。
  想每轮多锁一点可以到 0.5，不建议低于 0.2
- **杠杆**：长线不设止损 ≤3 倍；设了止损可以到 5 倍
- **K线周期**：1h 是甜点位。15m 周期噪音多、周期短，4h 信号少、单周期深；
  想改周期先在测试网对比跑
- 品种间参数不用再手动按 W 缩放了——这正是动态模式的意义，同一套配置放到
  BTC/ETH/SOL/NVDA 都会自动适配各自的带宽

## 六、上线前检查清单

1. 测试网先跑 3~5 天，核对日志里每层补仓价 vs 当时下轨值（策略弹窗预览或币安K线
   图上的 BOLL 都能对）
2. 确认每轮平仓的落袋 ≥ 保底利润
3. 表格状态列显示"运行中·动态W"才说明模式真的开了
4. 总保证金上限记得设（设置里/`max_total_margin`），这是瀑布行情的最后防线
