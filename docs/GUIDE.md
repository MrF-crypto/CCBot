# ccbot 操作指南（v3.0）

Binance USDT-M 合约网格/DCA 交易系统。本指南以 Windows/macOS 图形界面版为主，headless 版差异见文末速查与 [HEADLESS.md](HEADLESS.md)。

---

## 1. 安装与升级

| 平台 | 方法 |
|---|---|
| Windows | 下载 Release 的 `tradingbot-vX-win64.zip`，解压任意目录，运行 `TradingBot.exe` |
| macOS (M系列) | `tradingbot-vX-macos-arm64.zip`，解压后 `chmod +x TradingBot ccbot_headless && xattr -dr com.apple.quarantine .` |
| macOS (Intel) | 同上，用 `ccbot-macos-x64.zip` |
| Linux 服务器 | 源码编译 headless 版，见 HEADLESS.md |

**便携模式（v2.8+）**：全部数据（策略配置、交易明细、加密的API凭证、日志）保存在**程序目录的 `data/` 子目录**。升级 = 用新 exe 覆盖旧 exe（`data/` 不动）；换电脑 = 整个文件夹拷走（API Key 需重填一次，加密绑定机器是安全设计）。老版本 AppData 数据首次启动自动迁移。

## 2. 首次配置（三步）

1. **⚙ 设置** → 选**账户类型**（普通合约账户 / 统一账户），填 API Key / Secret（普通合约建议先勾"测试网"验证），保存

   > **统一账户（Portfolio Margin）**：走 `papi.binance.com`，币安**没有为它提供测试网**，选中后"测试网"勾选会自动禁用——连上即真实资金，没有空跑验证这一步。账户在币安开通统一账户后，普通合约的 API 端点会失效，同一个账户的 Key 不能在两种类型之间混用。连接成功的日志里会多一个 `uniMMR`（统一维持保证金率），统一账户按**全账户**计算强平，这个数掉到 1.x 就该处理了。

2. 同页配置 **账户总保证金上限**（强烈建议设置——瀑布行情的最后防线）和 **警报 webhook**（企业微信/飞书/Telegram，硬止损、对账异常、断线会推手机）
3. 主界面点 **连接**——之后每次启动若已存密钥会自动连接

> 单实例锁：同一台机器双开会被拒绝（防重复下单）。**多台设备不要同时连同一个账户**——这是目前唯一靠自觉的红线。

## 3. 添加品种与策略配置

主界面输入代币（如 `BTC`）→ 添加 → **右键品种 → 配置策略...**。新添加的 bot 默认**已停止**，配置好后点行内【继续】才开始。

### 3.1 基础网格参数

| 项 | 说明 | 建议 |
|---|---|---|
| 方向 | 多 / 空 / 双向 | 多（双向需币安双向持仓模式，单向模式下会被引擎拒绝） |
| 策略（曲线） | 每层资金分配 | **递增**（动态W甜点位）；倍投系深层资金爆炸慎用 |
| 预算USDT | 全部层加起来的名义价值上限 | 按品种分配，全账户总名义 ≤1.5×权益 |
| 杠杆 | 1~n | 长线不设止损 ≤3 |
| 最大层 | 子弹数（引擎上限10） | 6~10 |
| 间隔%/止盈%/追踪% | 固定参数 | **动态W开启后不生效**，可不管 |
| 止损%(0=禁用) | 均价回撤硬止损 | 长线可0；设的话放在覆盖深度之外 |
| 自动重启/冷却 | 止盈后等N秒重新等信号 | 冷却 ≥60s（0秒会在高位立刻回补） |

### 3.2 首单模式与指标

- **立即开仓**：点继续就市价开第1层
- **指标信号**（推荐）：等 1h（可选周期）BOLL 下轨 + RSI 条件满足才开首仓
  - RSI 确认方式选 **反转确认（cross）**：先探底（≤25）再回穿阈值（≥35），避免强跌中接刀
  - 弹窗底部有**实时指标预览**（当前价/上下轨/RSI/条件是否满足）

### 3.3 动态W模式（推荐开启）

勾选后间隔/追踪参数由实时布林带宽 W 自动推导（间隔=W/3、追踪止盈=0.15W、追踪建仓=0.1W）：

- **补仓锚定下轨**：跌够动态间隔 **且价格在带外** 才补——带子下移梯子跟着走，均价贴着下轨
- **止盈锚定上轨**：触上轨 + 盈利≥保底利润（默认 **2.0%**）才激活追踪
- 波动放大网格自动变疏，缩量自动变密，不用手动调参
- K线周期选 1h=震荡收割梯（覆盖~5-8%），4h=波段梯（覆盖翻倍、节奏减半）

详见 [DYNAMIC_W.md](DYNAMIC_W.md)。

### 3.4 趋势过滤（推荐开启）

4h EMA200+中轨斜率判定空头态：**暂停开新首仓 + 补仓间隔×1.5**。平时零存在感，单边下跌时替你踩刹车。日志可见"趋势状态切换"。

### 3.5 宏观许可层（v4.0.16 起）

三条**平级独立**的判据，任一不满足就不开新首仓。全部关闭 = 完全不参与。

| 开关 | 作用 | 建议 |
|---|---|---|
| ① 高位拦截（日线%B） | 价格在日线布林带中的相对位置高于阈值就不追 | **开**，阈值 **0.60**（walk-forward 4/4 段为正；0.80 太松≈没拦） |
| ② 24h涨幅拦截 | 币安界面上那个 24 小时滚动涨幅，超过阈值不追 | 默认 **0（关）**，无实证依据 |
| ③ 近7日涨幅拦截 | 相对 7 根日线前的收盘，滚动口径 | 默认 **0（关）** |

**三条口径正交**：%B 问「价格在波动区间的什么位置」，涨幅问「最近涨得多急」。窄幅横盘时 %B 可以贴着上轨而涨幅极小；急涨突破时涨幅巨大而 %B 未必越界——两者会给出相反的答案。

**勾选后数据缺失也不放行**（宁可错过不可乱开）。日志会区分「数据未就绪」与「条件不满足」，并且**三条数据线的就绪状态分开报**：%B 与 7日涨幅走日线 REST，24h 涨幅走 WebSocket 推送流，缺哪条报哪条。

> ⚠ v4.0.16 移除了原来的**结构层**（支撑拦截 / 净空拦截 / SR 区域检测 / 止盈锚定阻力区 / 结构性止损）。它需要每品种每 15 分钟拉 400 根 K 线做区域检测，占用共用线程池。历史实证结论仍存档在 [BACKTEST.md](BACKTEST.md)。

### 3.6 出场价记忆（v4.0.8）

```
多头：现价 ≤ 上次止盈价 × (1 − 回撤%)   才准重开
空头：现价 ≥ 上次止盈价 × (1 + 回撤%)
```

解决的是：**币爆拉一波、止盈出场、然后横在高位，机器人在山顶重新开首仓。**

上面那三条都是无记忆的相对指标，会随时间衰减到失效——24h涨幅 1 天后归零、7日涨幅 7 天后归零、%B 约 18 天后回落。价格横在高位不动，它们最终**全部放行**。这一条是唯一的绝对参照。

- **只记追踪止盈**：止损出场说明判断错了，锁死重入等于把亏损凝固
- **默认 30 天过期**：一个再也回不去的价位会把 bot 永久锁死
- 记忆随 bot 存盘，**程序重启后仍然生效**

埋伏型策略建议填 **10~15**；默认 0（关）。

### 推荐配置（v3.2 起即为默认值，新建 bot 无需手动设置）

> 方向多 · **递增曲线** · **2倍杠杆** · **10层** · 冷却 **300s** · 首单=**指标信号(反转确认 25/30, RSI周期14)**
> · ✅动态W（**保底利润 2.0%** · **固定补仓间隔 6**）· ✅趋势过滤 · ✅高位拦截（%B 0.60）

全部参数由回测实证确定（BTC/ETH/SOL/BNB 2025-01~2026-08 全量1m，walk-forward 4段，
约1200次回放），依据见 [BACKTEST.md](BACKTEST.md)。**这些默认值只影响新建的 bot**，
已有 bot 从配置文件恢复原参数不变——想套用需在策略配置里手动改。

## 4. 日常操作

| 操作 | 正确姿势 |
|---|---|
| 手动平仓 | **用程序里的【平仓】按钮**（正确记账/算盈亏/进冷却）。交易所App手动平仓是应急手段——程序会在下次平仓时收到 -2022 自动清空该bot并停止，你确认后点【继续】 |
| 停止/继续 | 【停止】保留仓位跟踪只停决策；【继续】恢复。全部停止后单个继续会自动重启引擎驱动 |
| 删除 | 只删得掉无在途订单的 bot；建议流程：停止 → 清除已停止 |
| 修改策略 | 右键→配置策略→保存。持仓中改杠杆要等下轮开首仓才对交易所生效 |
| 周期统计 | 【交易明细】按钮：按品种的周期数/周、胜率、平均层数+调参提示。**每周日15分钟例行**：杀低效品种、加高效品种、查资金费率、核对总名义≤1.5×权益 |

## 5. 看懂日志

| 前缀/内容 | 含义 |
|---|---|
| `[CCG] 第2/10仓多 qty=.. 均价=..` | 真实下单：补到第2层 |
| `[CCG] 追踪止盈 均=.. 收=.. P&L=..` | 一轮周期完成 |
| `[决策] XXX 首仓派发 @.. \| %B=0.52✓ \| 24h涨1.40%✓` | 宏观许可层的判定快照 |
| `行情WS已连接/收到首个数据包` | 连接与订阅状态。两条都有=数据在流；只有前者=订阅没生效 |
| `XXX 行情来源切换：标记价(WS) → REST兜底` | 价格源降级，只在【变化时】报 |
| `⚠ 对账: ...` | 启动时本地与交易所核对结果（外部平仓自动清空并停止/孤儿仓自动认领/手动加仓仅提示） |
| `趋势状态切换: 空头态...` | 趋势刹车踩下/松开 |
| `[-1021] Timestamp...` | 本机时钟漂移（程序已自动免疫+重对时；建议开系统时间自动同步） |
| `[-2022] ReduceOnly...` | 交易所无此仓位（外部已平）→ 程序自动清空该bot并停止 |
| `检测到网络异常` | 账户接口连续3次失败；恢复后自动"网络已恢复正常" |

## 6. 风控清单（实盘前逐条核对）

- [ ] 账户总保证金上限已设置
- [ ] webhook 已配置并测试收到过消息
- [ ] 全部 bot 满仓总名义 ÷ 权益 ≤ 1.5
- [ ] 杠杆 ≤3（不设止损时）
- [ ] 只有一台设备连接此账户
- [ ] 品种数 ≤50（动态W模式的安全容量）
- [ ] 新策略/新品种先测试网跑过

## 7. 故障速查

| 现象 | 处理 |
|---|---|
| 双开被拒 | 正常保护；确认无其他实例后删 `data/ccbot.lock` |
| 指标预览一直"拉取中" | 升级 ≥v3.0（拉取防堆积修复）；仍出现说明网络阻塞，查代理/VPN |
| bot 显示等待信号很久 | 看日志是否被趋势空头态/保证金上限/三层拦截挡住——都是功能不是故障 |
| 频繁 -1021 | 升级 ≥v2.9.1 + 系统时间开自动同步 |
| 想彻底重置某品种 | 停止 → 清除已停止 → 重新添加 |
